# Prime Fresh Oil Mills — B2B Manufacturer Web Portal

Prime Fresh Oil Mills is a B2B edible oil, seed processing, and agricultural commodity supplier website built for the eCell Qualification Challenge.

The platform is designed specifically for commercial bulk buyers, FMCG food processors, and private-label enterprises.

## Verified Business Scope
- **Hero Manufactured Product:** Pure Yellow Mustard Oil (extracted vegetable oil with natural pungency and golden viscosity).
- **Edible Seeds:** Graded Yellow Mustard Seeds, Black Mustard Seeds, Natural White Sesame Seeds, Cleaned Sesame Seeds, Black Sesame Seeds, Shelled Groundnut Kernels.
- **De-Oiled Cakes:** Nutrient-rich Yellow Mustard Cake and Black Mustard Cake for cattle feed formulations and organic soil enrichment.

## Key Features
- **Commercial Product Catalog:** Dynamic categorization (Oils, Seeds, Cakes) with technical specifications, visual forms, and commercial application tags.
- **Direct Mill Quotation Gateway:** Structured B2B quotation form with real-time validation for volume inquiries, packaging preferences, and evaluation sample requests.
- **Interactive Product Preselection:** Direct enquiry triggers pre-populate the quotation form for frictionless procurement routing.
- **B2B Procurement Planner:** Volume, packaging format, and delivery cadence estimator.
- **Responsive Architecture:** Mobile-first layout with smooth navigation drawer and accessible keyboard focus indicators.
- **Zero Hallucination / Verified Data:** Transparent handling of confirmed business details and unverified factory address placeholders.

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

### Local Production Preview
```bash
npm run preview
```
